# 📚 E-Learning Platform

A full-featured web-based E-Learning platform built with React.js that enables users to access lessons, watch video content, take exams, and interact with educational material through a modern and scalable interface.

---

## 🚀 Overview

This platform provides a complete learning experience, including lesson management, payment-based access, video streaming, and exam evaluation. It also includes an admin panel for managing content and users.

---

## ✨ Features

### 👨‍🎓 User Features
- Browse and explore available lessons
- Access purchased/enrolled lessons
- Watch video lessons with integrated player
- Interactive learning games
- Search and filter lessons
- Personalized dashboard (enrolled content)

### 💳 Payment System
- Unlock premium lessons through payment functionality
- Controlled access to paid content

### 📝 Exams System
- Take exams after completing lessons
- Evaluate user performance

### 🛠️ Admin Panel
- Manage lessons (Create / Update / Delete)
- Manage exams
- Control user access

## 🔄 Application Flow

1. User logs in / registers
2. User browses lessons
3. User searches or filters lessons
4. User purchases lesson (if premium)
5. User watches lesson video
6. User takes exam
7. Admin manages lessons and exams
